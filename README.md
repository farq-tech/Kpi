# جمعية قلبي

الأساس المعرفي والتنظيمي لـ **جمعية رعاية مرضى القلب (قلبي)** — الرياض، ترخيص المركز الوطني لتنمية القطاع غير الربحي رقم 1119.

الهدف من هذا الريبو: بناء مصدر حقيقة واحد عن الجمعية (الهيكل، الوظائف، البرامج، المانحين) تتفرع منه الأنظمة لاحقًا، والبدء بـ **التصميم التنظيمي (OD)**: من المهم، ما يُدمج، أين التضارب، أين ازدواج الوظائف — لخفض التكلفة وتوجيه الجهد.

## ابدأ من هنا
1. [`docs/01-understanding.md`](docs/01-understanding.md) — ما نعرفه عن الجمعية وما لا نعرفه.
2. [`docs/02-od-recommendations.md`](docs/02-od-recommendations.md) — التوصيات التنظيمية الأولية.
3. [`docs/od-findings.md`](docs/od-findings.md) — الجداول المولَّدة آليًا من البيانات.
4. [`docs/03-data-needed.md`](docs/03-data-needed.md) — ما أحتاجه منك لتحويل الفرضيات إلى أرقام.

## البنية
```
data/source/   الملف الأصلي كما استُلم (لا يُعدَّل)
data/raw/      جداول مستخرجة آليًا (المانحون، ملاءمة المشاريع)
data/org/      الهيكل: وحدات، وظائف، إسنادات، برامج، مجموعات مانحين
tools/         import_xlsx.py (استخراج) · od_analysis.py (تحليل)
docs/          الفهم، التوصيات، النتائج المولَّدة
```

## التشغيل
```bash
pip install openpyxl          # للاستيراد فقط
python3 tools/import_xlsx.py  # يعيد توليد data/raw و data/org/assignments.csv
python3 tools/od_analysis.py  # يعيد توليد docs/od-findings.md
```
التحليل نفسه بلا اعتمادات خارجية. عدّل ملفات CSV في `data/org/` ثم أعد التشغيل لتتحدث النتائج.

## تنبيه مهم
كل ما في `data/org/` عن الهيكل **مستنتج من متتبع المانحين**، وليس من هيكل معتمد. لا توجد في الملف أسماء موظفين ولا رواتب ولا مخطط تنظيمي. التوصيات فرضيات تحتاج تأكيدك.
